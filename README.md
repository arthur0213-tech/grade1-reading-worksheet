# 國小一年級「一頁四本」班級閱讀紀錄學習單 📚

> 🌐 **線上網頁直接使用（免安裝、支援手機/平板/電腦直接列印）**：  
> 👉 **[https://arthur0213-tech.github.io/grade1-reading-worksheet/](https://arthur0213-tech.github.io/grade1-reading-worksheet/)**

專為國小一年級（剛入學初學注音符號階段）學童設計的省紙、低門檻、同儕分享閱讀紀錄單產生器。  
一張 A4 紙張可記錄 4 本書，支援瀏覽器即開即用、一鍵列印與自訂版型切換。

---

## 🌟 設計理念與特色

### 1. 100% 臺灣國小標準直式右側注音
- 學習單上的所有字詞皆標註標準直式右側注音符號（含輕聲置頂、二三四聲右側）。
- 採用標準 Web CSS/HTML 排版，**免安裝任何特殊注音字型**，跨平台（Windows / Mac / iPad / Android）均能精準呈現。
- 一年級小朋友能自行拼讀所有題目與選項，不必依賴家長或老師逐字口述。

### 2. 一張 A4 記錄四本書（環保省紙雙模式）
- **📄 整張集點模式（預設）**：A4 四宮格排版，每讀完一本完成一格，集滿四本可請老師在頁尾頒發總認證章換取獎勵，減少零散單張紙張遺失。
- **✂️ 四格裁切卡模式**：點擊切換後自動顯示剪刀十字裁切虛線，印出後可裁成 4 張 A6 迷你小卡，便於張貼於聯絡簿、閱讀護照或教室布告欄。

### 3. 三種彈性版型（配合不同學習階段）
1. **🎨 圖文並茂版（預設推薦）**：上方寬敞畫框畫出最喜歡的場景/角色，下方附 2 行注音導引虛線，引導孩子寫下簡單字詞或造句。
2. **🖍️ 繪畫為主版**：適合開學前幾週，超大繪圖空間搭配底部單行「我想說：＿＿＿」，零寫字壓力。
3. **✏️ 注音格子版**：適合十月至下學期注音熟練後，附帶標準注音田字格（左字右聲調），供學生練習拼音書寫。

### 4. 🗣️ 同儕互動分享機制
- 每格底部皆設有 **「和同學分享，請同學簽名：＿＿＿＿＿＿」** 專屬欄位。
- 鼓勵孩子將讀完的故事向鄰座同學說一說、講一講，由聽完的同學簽名或寫上注音姓名，營造班級濃厚的閱讀分享氛圍。

### 5. 橫排圈選式評分
- 「我覺得：（請圈起來）」提供 **😊 喜歡**、**🙂 還好**、**🤔 有點難** 三個橢圓虛線框，讓孩子輕鬆動手圈選，即刻獲得閱讀回饋。

## 🖨️ 列印與輸出建議

1. **直接列印**：點擊頂端的綠色按鈕 **「🖨️ 直接列印 / 另存 A4 PDF」**，操作控制面板會自動隱藏，僅輸出乾淨的學習單。
2. **列印設定建議**：
   - 紙張尺寸：`A4`
   - 方向：`直向 (Portrait)`
   - 邊界：建議選擇「預設」或「無」；若邊界較貼邊，可將「縮放比例 (Scale)」微調為 `90% ~ 95%`。
   - 背景圖形：請勾選「背景圖形 (Background graphics)」。

## 🚀 線上使用方式

- 本專案採用純前端靜態技術（HTML5 + Tailwind CSS + Vanilla JS），無須架設伺服器。
- 點擊上方線上網址，或開啟 `index.html` 即可直接在現代瀏覽器（Chrome, Edge, Safari, Firefox）中執行。
